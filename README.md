# Каталог кімнатних рослин «Зелений дім»
 
Навчальний проєкт з дисципліни «Клієнтські технології Web-програмування».  
Студент: Чирва Данііл, група ІН-42/1. Варіант 4 — «Кімнатні рослини».
 
## Структура
 
```text
WEB-houseplants-project/
├── index.html      – каталог рослин
├── details.html    – сторінка деталей (монстера) + форма відгуку
├── about.html      – сторінка «Про проєкт»
├── admin.html      – таблиця рослин і форма додавання (навчальна імітація)
├── admin-edit.html – форма редагування рослини
├── docs/fields.md  – словник полів моделі
├── images/         – фото рослин (jpg, webp, avif), логотип, аватар
├── media/          – відеоінструкція (webm, mp4), постер, субтитри (vtt)
└── favicon.ico
```
 
## Лабораторна робота №2
 
Семантична сторінка-каталог із 6 карток `<article>`, формою додавання, блоком «Про мене» та `<aside>`.
 
## Лабораторна робота №3
 
- сайт із трьох сторінок зі спільною шапкою, меню (`aria-current="page"`) і підвалом;
- сторінка деталей: хлібні крихти, навігація «На цій сторінці», `<figure>` з `<picture>` (avif, webp, jpg), список визначень `<dl>`, таблиця догляду за сезонами;
- сторінка «Про проєкт»: списки `<ol>` і `<ul>`, відео з `<track>` і резервним вмістом, FAQ на `<details name>`, `<address>`.
 
Сторінки виконані без CSS і перевірені у W3C Validator.
 
## Лабораторна робота №4
 
- сторінка адміністрування `admin.html`: таблиця рослин і форма додавання;
- сторінка редагування `admin-edit.html`: та сама форма, заповнена даними калатеї, приховане поле `id`;
- форма відгуку на `details.html`: оцінка (radio), складність догляду (range), згода з правилами;
- посилання «Адміністрування» в підвалі всіх сторінок;
- усі форми надсилаються методом GET (статичний сервер не обробляє POST).
 
Словник полів моделі: [docs/fields.md](docs/fields.md).
