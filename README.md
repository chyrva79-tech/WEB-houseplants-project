# Каталог кімнатних рослин

Навчальний проєкт з дисципліни «Клієнтські технології Web-програмування».  
Студент: Чирва Данііл, група ІН-42/1. Варіант 4 — «Кімнатні рослини».

## Лабораторна робота №2

Сторінка-каталог, виконана тільки засобами семантичної розмітки HTML5, без CSS і JavaScript:

- шапка з логотипом, навігацією та пошуком;
- каталог із 6 карток `<article>` у списку `<ul>`: фото (`srcset`, `sizes`, `alt`), світло, полив (`<data>`), висота, місяць пересадки (`<time>`), безпечність для тварин, опис;
- форма додавання рослини;
- підвал з контактами.
